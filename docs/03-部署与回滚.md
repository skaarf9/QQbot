**数据库**：`data/koishi.db`（sqlite）。
`@koishijs/plugin-database-sqlite` 的配置项只有 `path` 一个字段，且是 **`.required()`——没有默认值**，
不写会直接校验失败。当前配置：

```yaml
  database-sqlite:w4sj7r:
    path: data/koishi.db
```

**市场插件必须配 `search.endpoint`**（原因见坑 10）：

```yaml
  market:ht45i0:
    search:
      endpoint: https://registry.koishi.chat/index.json
```
