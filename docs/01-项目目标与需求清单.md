# 项目目标与需求清单

> 属于 [QQ 机器人项目 —— 进度与交接](../进度与交接.md) 的分册。
> 旧编号（如「第八·十三节」）的去向见索引页的章节对照表。

需求清单是判定"做完了没有"的唯一依据。每条的验收状态见[索引页](../进度与交接.md)。

做一个**自建**（非 QQ 官方开放平台）的 QQ 群聊 AI 机器人：小号 + 协议端登录，避开官方机器人的内容审核链路。

### 原始需求清单（下称 R1–R14）

| # | 需求 |
|---|---|
| R1 | 接入 DeepSeek |
| R2 | 人格定义：默认人格（大肥鱼/DeepSeek 形象）+ 多份人格存储 + 命令切换 |
| R3 | 长短期记忆（基于群聊内容） |
| R4 | 与不同群成员的关系度/好感度区分 |
| R5 | 主动发表情包 |
| R6 | 识别表情包图片内容 |
| R7 | 表情包库 + 建立索引去重，避免重复识别同一张图 |
| R8 | 别人引用文字/图片并 @bot 时，理解引用内容（含图片）并合适回复 |
| R9 | 定时监控群聊、择机插话 |
| R10 | 避免"群里来一条消息就请求一次 API"（聚合/门控/冷却） |
| R11 | 会话生命周期（如"开始游戏"→"达成/中断"需终止） |
| R12 | 自我扩展：发现缺能力（如查天气）→ 搜插件 → 下载安装 → 运行 |
| R13 | **权限下发给指定用户**：部分命令需管理员，其余普通群友可用 |
| **R14** | **情绪控制：bot 根据对话内容动态调整自己的情绪，不同情绪下说不同的话** |

### 附加约束（用户明确）

- **避开官方 QQ 机器人线路**，走自建小号
- **倾向生态比较丰富的路线**
- 命令需要**权限分级校验**
